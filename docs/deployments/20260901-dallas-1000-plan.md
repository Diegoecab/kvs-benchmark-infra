## Cost boundary

Using public list prices as a planning estimate, the two E5 runners cost approximately USD 0.184/hour together and the provisioned NoSQL table approximately USD 0.178/hour, before boot volume, Object Storage, outbound transfer, tax, discounts, and negotiated pricing. A four-hour OCI NoSQL window is therefore approximately USD 1.45 plus those smaller variable charges. Leaving the stack running for a full 744-hour month would be roughly USD 270 before the same exclusions.

ADB and AWS are not included in that estimate or in this saved plan.
